# College Value Lab Demo Video Script

Target length: 1-3 minutes

## 0:00-0:15 - Hook

College can look affordable or unaffordable depending on whether you look at sticker price, average net price, aid, debt, or earnings. College Value Lab helps students compare those signals in one place and build a financially realistic college list.

## 0:15-0:35 - Profile

Start on Personal Profile. Enter:

- Home state
- Family income range
- Yearly amount covered without loans
- Maximum comfortable debt
- Academic focus
- Optional GPA, SAT/ACT, and extracurricular estimate

Say: These inputs do not predict the future. They personalize the comparison around aid assumptions, affordability, estimated borrowing need, debt comfort, major interest, and admissions realism.

## 0:35-1:05 - Explorer

Move to Explorer. Show:

- Search
- Filters for state, region, ownership, cost, graduation rate, and admissions fit
- Financial Survivability
- Personalized Value, or Major-Adjusted Value when a major/focus is entered
- Estimated yearly cost after aid
- Estimated Debt Need
- Admissions Fit

Say: The app separates financial fit from admissions realism so a student does not accidentally build a list only from reach schools.

## 1:05-1:35 - College Details

Click one school. Show:

- Yearly estimated cost after aid
- Earnings after graduation
- Earnings 10 years later
- Graduation rate
- Estimated Debt Need and typical median debt
- Merit Aid Signal if available
- Official calculator link

Say: The tool is a planning layer, not a final financial-aid answer. It pushes users to verify with each school’s official calculator.

## 1:35-2:10 - Selected Schools

Add 3-5 schools. Show:

- Status
- Personal Fit
- Official calculator estimate input
- Updated yearly cost used for decisions
- Updated estimated debt need
- Shortlist health warnings
- Balanced list guidance
- Export/restorable full progress JSON

Say: This turns the project from a ranking dashboard into a decision workflow.

## 2:10-2:35 - Validation and Limits

Show Validation & Testing and Methodology. Say:

I included validation worksheets and clear limitations because a score is only useful if users know what it can and cannot tell them.

## 2:35-3:00 - Close

College Value Lab uses public data, transparent scoring, and user testing to help students build more financially realistic college lists. The goal is not to replace counselors or financial-aid offices, but to make the first comparison clearer and more honest.
